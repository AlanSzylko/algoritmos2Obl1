# Herramientas previas: ecuaciones y matrices

## Resolver un sistema es describir todas sus soluciones

En un sistema lineal las incógnitas aparecen multiplicadas por números conocidos y sumadas; no se multiplican entre sí ni se elevan a potencias. El sistema Ax = b tiene matriz de coeficientes A y término independiente b. Si b = 0 es homogéneo y siempre admite x = 0.

Un sistema es incompatible si no tiene soluciones, compatible determinado si tiene una sola y compatible indeterminado si tiene más de una. Sobre R o C, un sistema lineal con más de una solución tiene infinitas: aparecerá al menos un parámetro libre.

**Operaciones de Gauss:** intercambiar dos filas, multiplicar una fila por un escalar no nulo y sumar a una fila un múltiplo de otra. Aplicadas a la matriz ampliada [A|b], preservan exactamente las soluciones porque cada operación tiene inversa.

Un pivote es el primer coeficiente no nulo de una fila no nula en una forma escalonada. Los pivotes van desplazándose a la derecha al bajar de fila; las filas cero quedan al final. Las incógnitas sin pivote son libres. Una fila [0 … 0 | c] con c ≠ 0 señala incompatibilidad.

## Ejemplo trabajado

Considerá x + 2y + z = 3 y 2x + 4y + 3z = 7. Restar dos veces la primera ecuación a la segunda da z = 1. Luego x + 2y = 2. Tomando y = t, todas las soluciones son:

= (x,y,z) = (2,0,1) + t(-2,1,0), con t ∈ R.

El vector fijo es una solución particular; la dirección (-2,1,0) resuelve el sistema homogéneo correspondiente. Si el segundo miembro cambiara, podrían cambiar la solución particular o la compatibilidad, pero el sistema homogéneo asociado seguiría siendo el mismo.

## Multiplicar matrices: tamaños y orden

Si A es m × n y B es n × p, AB es m × p. Su entrada (i,j) es la suma de productos de la fila i de A por la columna j de B. La columna j de AB también es A multiplicada por la columna j de B. Esta última interpretación explicará la matriz asociada.

El producto es asociativo: (AB)C = A(BC), y distributivo, pero en general AB ≠ BA. La identidad I tiene unos en la diagonal y ceros fuera; AI = IA = A con los tamaños apropiados. Una matriz cuadrada invertible tiene A⁻¹ tal que A⁻¹A = AA⁻¹ = I. Para obtenerla por Gauss se reduce [A|I] a [I|A⁻¹].

# Herramientas previas: determinantes y complejos

## Determinantes que se usarán en todo el apunte

El determinante es un escalar asociado a una matriz cuadrada. Para una matriz 2 × 2, det([[a,b],[c,d]]) = ad - bc. Para una de mayor orden se puede desarrollar por una fila o columna:

= det(A) = Σⱼ aᵢⱼ(-1)^(i+j) det(A sin fila i ni columna j).

Aquí i se mantiene fijo y se suman las columnas j. El patrón de signos empieza con + en (1,1) y alterna. En 3 × 3, por la primera fila: a₁₁(a₂₂a₃₃-a₂₃a₃₂) - a₁₂(a₂₁a₃₃-a₂₃a₃₁) + a₁₃(a₂₁a₃₂-a₂₂a₃₁).

**Reglas de cálculo:** una matriz triangular tiene determinante igual al producto de su diagonal; intercambiar dos filas cambia el signo; multiplicar una fila por c multiplica el determinante por c; sumar a una fila un múltiplo de otra no cambia el determinante. Las mismas reglas valen para columnas.

**Propiedades de apoyo:** det(AB) = det(A)det(B), det(Aᵀ) = det(A), y A es invertible si y solo si det(A) ≠ 0. En ese caso det(A⁻¹) = 1/det(A). Estas propiedades explican la conservación del determinante bajo semejanza.

En dimensión 2, si ad-bc ≠ 0, la inversa es (1/(ad-bc))[[d,-b],[-c,a]]. Podés verificarla multiplicando. La traspuesta Aᵀ intercambia filas y columnas; (AB)ᵀ = BᵀAᵀ, por lo que el orden se invierte.

## Números complejos para los ejercicios

C = {a+bi: a,b ∈ R}, con i² = -1. Se suman las partes reales e imaginarias por separado. Para multiplicar, se distribuye y se reemplaza i² por -1: (a+bi)(c+di) = (ac-bd)+(ad+bc)i.

El conjugado de z = a+bi es z̄ = a-bi. Si z ≠ 0, entonces 1/z = (a-bi)/(a²+b²). En particular 1/i = -i. Las ecuaciones lineales sobre C se resuelven igual que sobre R, pero los coeficientes y parámetros pueden ser complejos.

**Ejemplo de las diapositivas, tema 1, p. 11:** multiplicar v = (1+i,-3,0,i) por i da iv = (-1+i,-3i,0,-1). Se multiplica cada coordenada por el mismo escalar, no se conjuga el vector.

Si λ² + 3 = 0, no hay solución en R, pero en C las soluciones son ±i√3. Esta diferencia será decisiva al estudiar valores propios. Un mismo polinomio puede descomponerse completamente sobre C y no hacerlo sobre R.
