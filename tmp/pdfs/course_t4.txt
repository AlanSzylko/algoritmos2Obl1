# 4. Cambio de base: derivación y ejemplo original

## La identidad entre dos sistemas de coordenadas

Elegimos dos bases B y B' del mismo V. La matriz P=[Id]_(B←B') tiene columna j igual a [b'ⱼ]_B. La propiedad fundamental aplicada a Id da [v]_B=P[v]_B'. Como Id es invertible, P también lo es, y su inversa representa el cambio opuesto: P⁻¹=[Id]_(B'←B).

**El origen y destino se leen en la ecuación.** Esta convención evita la ambigüedad de decir simplemente «cambio de B a B'»: las columnas nuevas están escritas en la base vieja, así P recibe coordenadas nuevas y entrega viejas.

## Ejemplo de «4-cambio de base», pp. 1-2

En R², B=(e₁,e₂) y B'=((1,1),(1,2)). Como B es canónica, P se forma directamente con esos vectores como columnas:

MATRIX
P = [ 1  1 ]       P⁻¹ = [ 2 -1 ]
    [ 1  2 ]             [-1  1 ]

La primera columna de P⁻¹ expresa e₁=2(1,1)-(1,2). La segunda expresa e₂=-(1,1)+(1,2). Para v=(3,4), [v]_B'=(2,1), porque 2(1,1)+(1,2)=(3,4). Multiplicar P(2,1) reconstruye las coordenadas viejas.

## Derivar la fórmula general, p. 3

Sea A=[T]_(C←B), y sean P=[Id_V]_(B←B') y Q=[Id_W]_(C←C'). Para una entrada x'=[v]_B', el recorrido es x=Px', y=Ax, y'=Q⁻¹y. Sustituir da y'=Q⁻¹APx'. Como vale para todas las entradas:

= [T]_(C'←B') = Q⁻¹AP.

Es la misma fórmula que surge de T=Id_W∘T∘Id_V, cuidando las bases de cada identidad. P actúa en la entrada; Q⁻¹ en la salida. P es n×n, Q es m×m y A es m×n, por lo que el tamaño final sigue siendo m×n.

Para un operador T:V→V se usa la misma base vieja a ambos lados y la misma nueva a ambos lados. Entonces Q=P y queda A'=P⁻¹AP, la semejanza de matrices de la p. 4.

Si B y B' están dadas en coordenadas canónicas por M_B y M_B', entonces M_B[v]_B=M_B'[v]_B'. Despejando, P=M_B⁻¹M_B'. Así se obtiene el pasaje aun cuando ninguna base sea canónica.

# 4. Cambiar bases de entrada y salida distintas

## Aplicación de la fórmula general

Retomamos T:P₂→P₁, T(p)=p'. En las bases canónicas B₀=(1,x,x²), C₀=(1,x), su matriz es A₀=[[0,1,0],[0,0,2]]. Queremos la representación en B'=(1,x-1,(x-1)²) y C'=(1,x+1).

MATRIX
P = [ 1 -1  1 ]        Q = [ 1  1 ]
    [ 0  1 -2 ]            [ 0  1 ]
    [ 0  0  1 ]

P convierte las tres coordenadas de entrada nuevas a canónicas; Q convierte las dos coordenadas de salida nuevas a canónicas. Por tanto **no pueden reemplazarse por una sola matriz**, pues incluso tienen tamaños distintos.

MATRIX
A₀P = [ 0  1 -2 ]      Q⁻¹ = [ 1 -1 ]
      [ 0  0  2 ]            [ 0  1 ]

Q⁻¹A₀P = [ 0  1 -4 ]
         [ 0  0  2 ]

Se obtiene la misma matriz que calculamos transformando los vectores de B' y expresándolos en C'. La coincidencia verifica la fórmula mediante dos procedimientos independientes.

## Componer varios cambios de coordenadas

Si P recibe coordenadas en B' y devuelve en B, y R recibe coordenadas en B'' y devuelve en B', entonces PR recibe coordenadas en B'' y devuelve en B. La ecuación es [v]_B=P[v]_B'=PR[v]_B''. Invertir el recorrido da (PR)⁻¹=R⁻¹P⁻¹.

Esto explica también la transitividad de la semejanza: hacer dos cambios sucesivos equivale a uno solo, con el producto de las matrices de pasaje en el orden correspondiente.

## Método seguro al resolver

Escribí qué significa cada columna antes de multiplicar. Si las columnas son vectores de B' expresados en B, escribí [v]_B=P[v]_B' al lado de P. Construí por separado el cambio de salida si es distinto. Recién después usá A'=Q⁻¹AP.

Un control más corto que invertir P es verificar **AP=PA'** en el caso de un operador. Si ambas matrices representan correctamente la misma transformación, aplicar primero el pasaje y después A debe coincidir con aplicar A' y después el pasaje. Los ejercicios 1.13 y 1.14 muestran este control con operadores de polinomios y de matrices.
